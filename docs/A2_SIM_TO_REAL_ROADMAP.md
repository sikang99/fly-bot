# 시뮬레이션 → 실물 적용 절차

작성: 2026-09-29. 대상: A2 Pro + 외장 Jetson Orin NX 16GB + PiPER-X.

이 문서는 구현·검증 계획이며 실물 운용 승인이나 성능 보장이 아니다. 현재 시뮬레이터의 팔은 시각 동작이며 커넥톰 연결은 로봇 상태를 관찰하는 단방향 입력이다. GLB는 외형 교환 자료로 관성·구동기·안전 제어를 포함하지 않는다.

현재 보행은 규칙 기반 제어와 시뮬레이션 위치 보조를 포함하며, 경로점 보상은 점수 누적이다. 학습 완료된 A2 정책 checkpoint가 생성된 상태가 아니다. 학습 정책을 사용할 경우 별도 학습·입출력 계약·기준 데이터 검증을 거쳐야 한다. 기존 배포 도구는 진단·패키징·파일 검증·오프라인 추론 범위이고 실제 센서 Shadow나 SDK 명령 송신을 구현하지 않는다. 기존 도구 사용법은 [JETSON_DEPLOYMENT.md](JETSON_DEPLOYMENT.md)를 참조한다.

## 단계별 산출물과 승인 조건

| 단계 | 작업 | 다음 단계로 진행하기 위한 증거 |
|---|---|---|
| 1. 구성 확정 | 실제 펌웨어·SDK 호환성, 센서 접근 권한, 팔/그리퍼 리비전, 장착 위치·질량 확인 | 장비/버전 목록과 좌표계 문서. 미확인 값은 추정으로 표시 |
| 2. 모델 보정 | A2·PiPER-X·STEP 하우징 통합, 무게중심·관성·충돌·관절 한계 설정 | 초기 자세 간섭 없음, 정지/적재 보행/팔 동작 회귀. 시뮬레이션 위치 보조와 실제 제어의 차이 기록 |
| 3. 제어 경계 | 행동 계획과 하위 구동 분리. A2 공식 고수준 SDK 및 팔 전용 SDK 어댑터 작성 | 단위·좌표·부호·모드·반환 코드·권한 확인. 시뮬레이터 관절 토크를 그대로 전달하지 않음 |
| 4. Jetson 준비 | 호환 JetPack·드라이버·SDK 고정, 모델 최적화·워밍업, 서비스·로그·롤백 준비 | 패키지 버전/해시, 재부팅 동작, 메모리·온도·부하 측정. 기존 배포 도구의 존재를 실물 SDK 구현 완료로 간주하지 않음 |
| 5. Shadow | 실제 센서 취득·시간 동기화·외부 파라미터 보정 후 판단만 실행 | 구동 출력이 차단되어 있음을 확인. 누락·오검출·프레임 지연·후방 위험 판단 로그 검토 |
| 6. 제한 구동 | 통제 구역에서 감독자·수동 개입 확보. 접힌 팔, 정지·저속 직진·회전부터 고정 장애물까지 | 정지/통신 단절/제어권 전환을 먼저 검증. 안전 정지를 무조건 Passive나 전원 차단과 동일시하지 않음 |
| 7. 통합 검증 | 이동 장애물·협로·후방 접근·경로점·정지 후 팔 작업, 센서/프로세스/통신 장애 주입 | 충돌·전도·이탈·오작업·회복 실패 기록. 위험 조건은 재생/HIL부터 검증하고 사람을 충돌 시험 대상으로 사용하지 않음 |
| 8. 운용 승인 | 실측 기준에 맞춰 속도·가속·안전거리·명령 유효시간을 결정 | 승인된 구성/환경 범위 명시, 버전 고정, 제한 운용, 모니터링·중단·롤백 절차 |

## 실물 신호 구조

센서/로봇 상태 → 빠른 위험 판단 및 영상 인식·경로 계획 → 독립 안전 중재 → A2 공식 고수준 SDK / PiPER-X SDK.

커넥톰은 향후 검증할 행동 제안 경로다. 긴급 판단이 커넥톰이나 영상 추론 완료를 기다리지 않도록 한다. 물리 긴급정지는 Jetson 애플리케이션의 정상 동작에만 의존해서는 안 된다. 로봇의 실제 안전 인터페이스와 제조사 절차를 확인한다.

## 지연과 승인 지표

- 센서 취득, 판단 완료, 명령 송신, 로봇 상태 응답, 실제 몸체 반응 시각을 구분한다. 명령 수락은 몸체 반응과 다르다.
- 평균뿐 아니라 P95/P99·최악 지연, 센서 데이터 나이, 명령 누락, 온도·스로틀링을 기록한다.
- 도착률, 경로 이탈, 충돌/근접, 자세 불안정, 실제 제동거리, 팔 간섭 및 실패 복구를 평가한다.
- 정적 장애물 안전거리의 기본 예산은 지연 중 이동거리 + 실측 제동거리 + 불확실성 여유다. 동적 장애물은 상대 운동과 예측 오차를 추가한다.
- 일률적인 지연/속도 합격값을 이 문서에서 보장하지 않는다. 실제 센서·펌웨어·적재·지면·운용 환경의 측정으로 결정한다.
