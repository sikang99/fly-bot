# 경로 편집기

상단 **경로 편집기**를 누르면 같은 시뮬레이션 안에서 별도 편집 화면으로 전환한다. 페이지를 새로 열거나 초기화하지 않으므로 경로·장애물을 유지한다. 자동/수동 주행과 진행 중 팔 작업을 중단하고 Stand에서 편집한다.

1. 새 경로점 동작(이동만/앞/왼쪽/오른쪽 팔 작업)을 선택하고 지도 바닥을 클릭한다.
2. 목록의 X/Y 좌표(m), 작업 선택, 앞/뒤 순서 버튼으로 대기 경로점을 편집한다. 개별 삭제 또는 전체 지우기도 가능하다. 완료된 경로점은 표시를 유지하며 편집하지 않는다.
3. 장애물 편집을 펼쳐 생성·크기 변경·삭제한다. 지도 장애물은 드래그로 이동한다. 빈 바닥 드래그는 지도 이동, 휠은 확대/축소다. 경로 전체 보기로 구도를 다시 맞춘다.
4. **주행 화면**으로 돌아가 **Walk**를 눌러 이동을 시작한다. 화면 전환만으로 주행하지 않는다.

주행 화면에서는 바닥 클릭으로 경로를 추가하거나 장애물을 끌지 않는다. 수동 조작·데모·고급 설정·상세 상태는 접이식 영역으로 정리했으며 Manual을 선택하면 수동 조작 영역이 열린다. 긴급 정지는 두 화면 모두 상단에서 사용할 수 있다.

변경은 현재 세션에 즉시 반영된다. 파일 저장/불러오기는 아직 없으며 새로고침하면 초기화된다. 편집 화면은 로봇 주행을 정지하지만 시뮬레이션 시간과 기존 동적 장애물 이동은 계속된다. 실제 로봇 제어용 편집기가 아니다.
