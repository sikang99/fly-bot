# 경로점 팔 작업

장착 모델은 사용자 지정 **AgileX PiPER-X**이다. [공식 제품 설명](https://global.agilex.ai/products/piper-x)은 6-DoF로 명시한다. 화면은 베이스 회전·어깨·팔꿈치·전완 회전·손목 굽힘·툴 회전의 6축 개략 표현이며 제조사 전용 CAD/URDF를 적용한 정밀 모델은 아니다. 기존 크기(0.75 배율)와 앞다리 위 장착 위치를 유지한다. 앞/옆 작업에서는 추가된 두 회전축을 중립으로 유지한다. 표시 관절각을 실제 PiPER-X 명령에 직접 사용하면 안 된다.

왼쪽 **경로점 작업 → 새 경로점 동작**에서 작업을 고르고 바닥을 클릭한다.

- 이동만: 기존 경로점 동작.
- 팔 앞으로 뻗기: 도착 시 로봇 전방(+X)으로 뻗기.
- 팔 몸 왼쪽 / 오른쪽: 도착 당시 몸 기준 좌우(±Y)로 뻗기.
- 양쪽 흔들기: 몸 기준 왼쪽으로 뻗고, 전방을 거쳐 오른쪽으로 흔든 뒤 접기(1회).

기존 대기 경로점은 아래 목록에서 작업을 변경할 수 있다. 작업 경로점은 보라색이며 완료 후에도 표시된다. 실행 중이거나 완료한 작업은 편집하지 않는다.

몸 중심이 기존 도착 허용 범위에 들어오면 도착 보상을 한 번 지급한다. Stand에서 1초 정착, 2초 펼치기, 2초 작업 자세 유지, 2초 접기를 수행한 뒤 다음 경로점으로 이동한다. 마지막 작업 후에는 Stand로 남는다.

양쪽 흔들기는 총 11초(시뮬레이션 시간)이다. 1초 정착 → 2초 왼쪽 펼치기 → 1초 유지 → 3초 오른쪽으로 이동 → 2초 유지 → 2초 접기 순서로 수행한다. 좌우는 작업 시작 시 로봇 몸 기준이며, 관절각은 구간 경계에서 연속적으로 연결된다.

수동 전환, 명시적인 운용 모드 변경, 긴급정지, 초기화 또는 경로점 삭제 시 실행 중 작업을 취소하고 시각 팔을 접는다. 취소된 경로점을 유지한 경우 Walk로 재개하면 해당 작업을 다시 수행하며 도착 보상을 중복 지급하지 않는다.

## 수동 조작

Manual Mode를 켜고 Walk를 선택하면 화면 방향 버튼 또는 화살표를 누르는 동안 이동한다. ↑/↓는 전진/후진, ←/→는 몸 기준 옆걸음이다. 회전은 별도 화면 버튼 또는 Shift+A/D를 사용한다. 입력을 놓으면 정지 명령으로 바뀌며 실제 속도는 기존 감속 제한에 따라 줄어든다. 페이지 포커스 상실·긴급정지 시 재활성화가 필요하다. 자동 장애물 회피는 꺼진다.

Stand/Walk 아래 팔 방향 선택과 **팔 작업 / 팔 원위치** 버튼을 제공한다. Manual+Stand에서 작업을 시작하며 기존 방향 작업은 7초, 양쪽 흔들기는 11초 시각 작업 후 접힌다. 원위치는 작업을 즉시 취소해 접힌 자세로 복귀한다(연속 귀환 궤적이 아닌 시각 초기화). Walk 등 모드를 바꾸면 작업이 취소된다. 수동 작업은 경로점 완료나 보상을 발생시키지 않는다.

## 시뮬레이션 한계

현재는 동작 순서와 화면 확인을 위한 **시각 시뮬레이션**이다. 팔의 질량·접촉·파지·주변 장애물과의 충돌 검사는 없다. 작업 중 자동 회피는 실행하지 않는다. 실제 로봇팔 제어·배포 기능이 아니며 실물 적용 전 팔 SDK, 작업 공간 검사, 접촉 안전 및 이동체 접근 시 작업 중단 절차가 별도로 필요하다.

검증: `node --test test/a2-arm-work.test.js` 및 전체 `npm test`.
