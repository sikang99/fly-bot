# A2 상태 → 커넥톰 관찰 연결

상단 커넥톰을 열면 로봇 시뮬레이션 상태를 10Hz로 전달하고, 기존 WASM LIF 엔진을 자동 실행한다. 표시 밝기는 실제 엔진의 trace이며 임의 애니메이션이 아니다. Run/Pause로 신경망만 중지·재개할 수 있고, 창을 닫으면 상태가 초기화된다.

## 실험적 입력 매핑

| 로봇 상태 | 커넥톰 그룹 | 외부 Poisson 자극 |
|---|---|---|
| 측정 전후/측방 속도 크기 | vnc_sensory | 0–120Hz |
| 회전 명령 크기 | ascending_neuron | 0–100Hz |
| 회피 활성 상태 | visual_projection | 100Hz 또는 0 |
| 팔 작업 활성 상태 | descending_neuron | 100Hz 또는 0 |

각 그룹에서 데이터 순서에 따라 균등하게 최대 64개 뉴런을 선택한다. 이는 생물학적으로 검증된 특정 뉴런/행동 대응이 아니라 **엔지니어링용 상태 인코딩 실험**이다. 전후·좌우 방향은 현재 부호 없이 강도만 반영한다. 현재 이동체 관측은 시뮬레이션 정보이며 카메라 픽셀/실물 LiDAR 입력이 아니다.

동일 origin의 부모 창만 입력으로 받는다. 500ms간 입력이 없거나 Passive/오류이면 외부 자극을 0으로 만든다. 이미 발생한 활동은 신경망 동역학에 따라 남을 수 있어 즉시 모든 뉴런이 꺼진다는 뜻은 아니다. 시간은 신경망 가상 시간이며 브라우저 부하에 따라 실제 시간과 다를 수 있다.

**출력은 화면 관찰에만 사용한다. 커넥톰 → A2 제어 명령 경로는 없으며, 폐루프 신경 제어·학습·T1/T2/T3 형태학적 매핑을 구현한 것은 아니다.** A2 제어와 안전 보호는 기존 별도 worker가 담당한다.
