주행 데모

경로 편집기

편집 중 로봇은 Stand로 정지합니다. 바닥 클릭: 경로점 추가 · 드래그: 지도 이동 · 휠: 확대. 장애물은 드래그로 이동합니다. 변경은 즉시 반영되며 주행 화면으로 돌아가 Walk로 시작하세요. 새로고침 시 초기화됩니다.

경로점 작업

동작 선택 후 바닥 클릭. 아래 목록에서 대기 경로점의 작업을 변경할 수 있습니다. 도착 → 정지 → 뻗기 → 2초 유지 → 접기 → 다음 지점. 방향은 도착한 로봇 몸 기준입니다. 팔은 시각 시뮬레이션이며 접촉·파지·팔 충돌 검사는 아직 없습니다.

■ 초록: 단차 높이 2cm 이하 · 통과
■ 주홍: 2cm 초과 단차 / 상자 · 회피
단차·상자를 클릭하여 선택하고 드래그하여 이동합니다. 통과 기준은 시뮬레이터 전용입니다.

녹색 화살표가 전방(+X) · 목록 좌표는 월드 X/Y(m) · 몸 중심이 경로점에 도착하면 완료합니다.

장애물 편집

양보 0 · 복귀 0 · 대기 0

사람은 옆으로 비킨 뒤 원래 경로로 복귀합니다. 공간이 없으면 기다립니다. 해제하면 기존 직진 장애물로 시험합니다. 실제 사람의 양보를 보장하지 않습니다.

자동 출현은 8–14초 간격으로 경로 앞쪽 옆에서 생성하고 12초 후 제거합니다. 수동 생성은 Y방향 왕복 이동합니다. 자동 출현은 주행을 유지합니다.

화면에서 장애물을 선택하세요. 생성은 로봇에서 X/Y 각각 +2m 위치, 편집 시 Stand 정지. 최대 32개. 새로고침 시 초기화됩니다.

고급 주행 설정

Velocity command

관절 보행 명령 상한은 0.6 유지 · 열린 직선 구간에서는 위치 보조로 실측 약 1m/s. 목표·장애물 2.5m 전부터 감속합니다. 실제 로봇 제어값이 아닙니다.

실제 관절 자력 기상이 아닌 3초 자세 보조입니다. 주변 공간 확보 후 최대 2회 시도하며 Passive로 취소합니다.
